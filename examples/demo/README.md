# Synthetic demo fixture

All files in this directory are synthetic software-test inputs authored for MRDskill's offline reproducibility demo and dedicated to the public domain under [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/). No patient records, real paper text, real identifiers, benchmark observations, or sourced clinical assertions are included.

The long retrieval text is a vocabulary fixture only. It intentionally contains no medical rule or conclusion. Do not use these files for biological interpretation, benchmark claims, or clinical decisions. `examples/expected/` contains small, precomputed outputs from the same synthetic fixture and existing MRDskill scripts.
